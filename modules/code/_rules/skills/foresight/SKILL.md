# Foresight

"If only we had thought of this earlier"; the thought we shouldnt be having.
Always workout where the user wants to go, how will this feature evolve, where are the boundaries.
Thinking a few steps ahead; what future upgrade should we be ready for today? Design with that in mind.

Prioritize maintainability, upgradability, sustainable database sizing, and scalability.
If a future migration can be avoided by designing it correctly now we should.

## Examples

"We are adding Social Sign In with intial GitHub support. Down the road, the user wants other providers like GitLab or a self-hosted forgejo. We should plan the database now expecting different SSO's be linked to one user"
