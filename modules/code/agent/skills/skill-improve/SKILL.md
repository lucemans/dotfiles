# Skill Improvement Helpdesk

Welcome to the skill improvement helpdesk, if you are reading this you might have run into an issue with a skill document due to a framework update, a change in user set out requirements, an incorrect code snippet, or anything of the sorts.
You've come to the right place!

## Report the problem to the human

When encountering a problem surface it to the human, tell them `I ran into a problem with the solid-js skill` and ask them if you should document it.

## Write it out like a champion

You get the size of a tweet, state whats wrong, leave a note, suggest an improvement, or just wish the receiving agent a good day.
Save your tweet-sized report as markdown `.md` in the `.tmp/feedback` folder, for example `.tmp/feedback/skill-improve-too-cheerful.md`.
Ensure to notify the human of its absolute path, so they can take action and improve the skill.
You will hear back from us in 1 to ... soon™ business days.
