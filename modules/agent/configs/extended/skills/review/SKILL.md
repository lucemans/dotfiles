# Review Guide

Rate out of 10; 5.5 = 'good enough'

## Logic Review
Find broken states, spot decision or intent changes, spot edgecases

## Repo Quality Review
Rid comments; Veto README edits; Decline tests; Reject wrongful commits

## UI/UX Review & Regressions
Spot the change; Verify the posted before/afters are accurate; Flag redundant text, verbose prose & misimplemented behaviour
