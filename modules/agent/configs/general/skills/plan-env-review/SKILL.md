# Plan Env Review

View the plan-env-md documents using a browser
Assume no prior understanding of what the document is about

## Criteria

If any of the following criteria fail send it back:

- Immediately clear what document is about
- Renders on desktop, not half-width page, not phone width
- Properly used /visualize (charts, images, visualizations) and can be quickly visually scanned
- Not majority text or wall of text
- Properly uses negative space and visually even padding 
- Has accurate brand marks, logos, functional imagery
- If a design proposal or variations on a design, the remaining ui is accurate to the reference
